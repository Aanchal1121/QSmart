Indian Telecom & DLT Gateway Architecture
Mock Mode Active

In development, outgoing SMS messages are logged to database & SLF4J console via MockSmsProvider. For production in India, connect via TRAI-mandated DLT compliance:

  • TRAI / DLT Registration: Principal Entity registration on telecom portals (Jio, Airtel, Vodafone Idea, BSNL).
  • Registered Header: 6-character alpha Sender ID (e.g., QSMRT / QSMART).
  • Template Approval: Explicitly approved DLT transactional templates with variable tags ({#var#}).
  • 2-Way Inbound: Dedicated Long Code (10-digit) or Short Code (5-digit) sending webhooks to POST /api/sms/webhook.
  • Aggregator APIs: Supported providers: Gupshup, Textlocal, Exotel, Kaleyra, Twilio.
